# PairTrace-Doc v0.1.0

Initial research-code release accompanying the IJDAR submission.

Included:

- configuration-driven PairTrace-Doc source code;
- reference-only round-trip and comparison pipelines;
- IJDAR experiment configurations and frozen protocol metadata;
- self-contained unit and pipeline tests;
- a three-record toy sanity fixture;
- aggregate manifests and SHA-256 identities permitted for redistribution.

Excluded:

- third-party dataset pixels;
- credentials and private access records;
- prediction caches;
- trained checkpoint bytes;
- author photographs and submission-only personal materials.
