# Data and model-weight availability

No third-party dataset pixels are redistributed in this code release.
AIForge-Doc, Text Forensics Reasoning, FantasyID, and DESCAN-18K remain subject
to their upstream access and licensing terms. Users must obtain any required
data directly from the respective providers.

No trained checkpoint bytes are included. The release may include checkpoint
filenames, roles, expected SHA-256 values, and frozen protocol metadata when
those records are necessary to identify the evaluated artifacts. Such metadata
does not grant permission to redistribute the corresponding checkpoint bytes.

The included `data/toy/debug_predictions.jsonl` file is a three-record
synthetic schema fixture. It is not research data and is never paper evidence.
