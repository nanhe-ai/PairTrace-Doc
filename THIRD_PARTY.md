# Third-party software and artifacts

This repository declares Python dependencies in `pyproject.toml` but does not
redistribute their source code. Each dependency remains governed by its own
license.

Optional external baselines, pretrained weights, datasets, OCR systems, and
document editors are not bundled. References to an upstream project, package,
checkpoint, or dataset identify the experiment dependency only; they do not
change the upstream provider's license or access conditions.

Users are responsible for reviewing and complying with upstream terms before
downloading data or weights, executing optional baselines, or redistributing
derived artifacts.
