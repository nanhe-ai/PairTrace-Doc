# Draft DESCAN-18K License Clarification Request

Status: draft only; not sent.

Subject: Clarification of permitted research use for DESCAN-18K

Dear DESCAN-18K authors,

We are preparing a noncommercial academic evaluation of paired document-image change localization using the official DESCAN-18K test archive. The public materials identify the Raspberry Pi magazine source pages as CC BY-NC-SA 3.0 and describe the dataset as a public research benchmark, but we could not find an explicit license for the dataset release itself.

Could you please confirm whether the following use is permitted?

1. download and locally process the official `Test.zip` archive for noncommercial research;
2. create deterministic localized edits and changed-pixel masks for evaluation;
3. publish aggregate metrics and qualitative figures with attribution;
4. release code, archive/member checksums, pseudonymous manifests, transformation parameters, and predictions, while not redistributing the original or altered DESCAN images.

If there is a preferred dataset license, citation, attribution string, or additional restriction, please let us know.

Thank you.
